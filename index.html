Cómo funciona: esta página se actualiza sola todos los días después de las 13:00 (Montevideo) con las publicaciones de MercadoLibre Uruguay e InfoCasas que cumplen los criterios de cada zona. Se agregan las nuevas y se quitan las que ya no están publicadas (vendidas o dadas de baja). Un mismo apartamento puede aparecer dos veces si está publicado en los dos sitios. La etiqueta "Publicado hoy / esta semana" es la que muestra MercadoLibre. Tocá el título para abrir la publicación.
